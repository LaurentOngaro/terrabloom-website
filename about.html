La Philosophie

Je crois que les jeux de survie ont perdu quelque chose en route. Ils sont devenus stressants, exigeants, punitifs.

Avec TerraBloom, je veux revenir à l'essentiel : la satisfaction de construire quelque chose qui dure.

  • Pas de Crunch : Le jeu est développé à un rythme humain, pour des humains.
  • Pas de FOMO : Tu joues quand tu veux. Le monde t'attend.
  • Qualité > Quantité : Je préfère trois mécaniques polies à la perfection qu'une centaine de features buggées.
"Un jeu doit être un refuge, pas une seconde liste de tâches."

Ma Boîte à Outils

🏗️

Architecture

J'aime quand le code est propre. ScriptableObjects, Event Channels, découplage... Si l'architecture est saine, le jeu est sain.

⚡

Performance

Un jeu qui rame, c'est non. Je passe autant de temps dans le Profiler que dans l'éditeur. L'optimisation n'est pas une option.

🎨

Tech Art

Shaders, VFX, Lighting. Je ne suis pas un artiste traditionnel, mais je sais faire chanter les pixels avec du code.

🔧

DevOps

Automatisation, CI/CD, Versioning. Parce que perdre du temps sur des tâches répétitives, c'est du temps en moins pour le jeu.
