Politique de Confidentialité

Dernière mise à jour : 6 janvier 2026

1. Introduction

Cette politique de confidentialité décrit comment TerraBloom collecte, utilise et protège vos données personnelles. Nous prenons la protection de votre vie privée au sérieux et nous engageons à respecter le RGPD (Règlement Général sur la Protection des Données).

2. Données Collectées

Nous collectons uniquement les données que vous nous fournissez volontairement :

  • Informations de contact : Nom et adresse email (via le formulaire de contact)
  • Contenu des messages : Informations que vous choisissez d'inclure dans vos messages
  • Données analytiques : Informations de navigation anonymisées (pages visitées, durée, type d'appareil) via Google Analytics

3. Utilisation des Données

Vos données sont utilisées exclusivement pour :

  • Répondre à vos questions et demandes
  • Améliorer le contenu et l'expérience du site
  • Analyser l'utilisation du site de manière anonyme

4. Base Légale (RGPD)

Le traitement de vos données repose sur :

  • Votre consentement explicite lorsque vous utilisez le formulaire de contact
  • L'intérêt légitime pour l'analyse anonymisée du trafic

5. Vos Droits

Conformément au RGPD, vous disposez des droits suivants :

  • Droit d'accès : Demander une copie de vos données
  • Droit de rectification : Corriger vos données
  • Droit à l'effacement : Demander la suppression de vos données
  • Droit à la portabilité : Recevoir vos données dans un format lisible
  • Droit d'opposition : Refuser le traitement de vos données

Pour exercer ces droits, contactez-nous via le formulaire de contact.

6. Partage des Données

Vos données sont partagées uniquement avec les services essentiels :

Formspree (Formulaire de Contact)

  • Service conforme RGPD utilisé pour traiter les messages du formulaire de contact
  • Politique de confidentialité : Formspree Privacy Policy

Google Analytics

  • Utilisé pour analyser le trafic de manière anonymisée
  • Les données sont anonymisées et ne permettent pas de vous identifier personnellement

Nous ne vendons jamais vos données à des tiers.

7. Sécurité des Données

  • Connexion sécurisée HTTPS sur l'ensemble du site
  • Pas de stockage local de données personnelles
  • Traitement des messages via Formspree (serveurs conformes RGPD)

8. Cookies

Ce site utilise des cookies strictement nécessaires au fonctionnement :

  • Préférences de thème (clair/sombre)
  • Préférence de langue (FR/EN)
  • Google Analytics (anonymisé)

Aucun cookie de suivi publicitaire ou de profilage n'est utilisé.

9. Durée de Conservation

  • Messages de contact : 1 an pour les archives de communication
  • Données analytiques : 26 mois (politique Google Analytics)

10. Modifications

Cette politique peut être mise à jour. Les modifications importantes seront signalées sur cette page avec une nouvelle date de mise à jour.

11. Contact

Pour toute question concernant cette politique ou vos données personnelles :

  • Utilisez le formulaire de contact
  • Retrouvez tous les liens sur la page À Propos
