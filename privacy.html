Politique de Confidentialité

Dernière mise à jour: 2 janvier 2026

1. Introduction

Chez TerraBloom ("nous", "notre" ou "nos"), nous prenons la protection de vos données personnelles très au sérieux. Cette Politique de Confidentialité explique comment nous collectons, utilisons, protégeons et partageons vos données personnelles.

2. Données Que Nous Collectons

Nous collectons les données suivantes uniquement si vous les fournissez volontairement:

  • Informations de Contact: Nom, adresse email (lorsque vous nous contactez ou vous inscrivez à la newsletter)
  • Contenu du Message: Toute information que vous incluez dans vos messages de contact
  • Données Analytiques: Pages visitées, durée de visite, appareil utilisé (via Google Analytics - optionnel)

3. Comment Nous Utilisons Vos Données

Vos données sont utilisées uniquement pour:

  • ✅ Répondre à vos questions et demandes
  • ✅ Vous envoyer la newsletter TerraBloom (si vous avez consenti)
  • ✅ Améliorer notre site web et notre contenu
  • ✅ Détecter et prévenir les abus

4. Base Légale (RGPD)

Nous n'utilisons vos données que si vous avez consenti explicitement.

En vertu du RGPD (Règlement Général sur la Protection des Données), nous respectons:

  • ✅ Consentement explicite: Vous devez cocher une case avant de vous inscrire à la newsletter
  • ✅ Droit d'accès: Vous pouvez demander une copie de vos données
  • ✅ Droit à l'oubli: Vous pouvez demander la suppression de vos données
  • ✅ Droit de rectification: Vous pouvez corriger vos données
  • ✅ Droit à la portabilité: Vous pouvez recevoir vos données dans un format lisible

5. Partage de Données avec des Tiers

Nous partageons vos données uniquement avec les services essentiels:

Formspree (Formulaires de Contact)

  • Votre nom et email sont transmis à Formspree pour traiter vos messages
  • Formspree respecte le RGPD
  • Les données ne sont conservées que pour vous envoyer des réponses

Pas d'Autres Partages

Nous ne vendons pas, n'échangeons pas et ne partageons pas vos données avec d'autres entreprises.

6. Sécurité des Données

Nous utilisons des mesures de sécurité standard pour protéger vos données:

  • ✅ HTTPS pour tout le site (certificat SSL)
  • ✅ Pas de bases de données locales contenant vos données personnelles
  • ✅ Formspree gère le stockage sécurisé des messages
  • ✅ Pas de cookies de suivi ou de profilage

7. Cookies

Notre site utilise uniquement les cookies strictement nécessaires pour le fonctionnement:

  • Aucun cookie de suivi publicitaire
  • Aucun cookie de profilage comportemental
  • Pas d'intégration avec Meta, Google Ads, TikTok, etc.

8. Stockage des Données

  • Messages de Contact: Stockés par Formspree (serveurs US/EU conformes RGPD)
  • Newsletter: Aucun stockage local. Gérée via Formspree ou service email externalisé
  • Analytiques: Google Analytics (anonymisé, avec consentement)

9. Droits RGPD - Comment Exercer Vos Droits

Pour exercer vos droits (accès, suppression, rectification), contactez-nous:

  • 📧 Formulaire de Contact
  • 𝕏 Message Direct sur X

Nous répondrons dans un délai de 30 jours comme l'exige le RGPD.

10. Durée de Conservation

  • Messages de Contact: Conservés 1 an pour les archives de communication
  • Newsletter: Conservés tant que vous êtes inscrit
  • Analytiques: Conservés 26 mois (politique Google)

11. Modifications de Cette Politique

Nous pouvons mettre à jour cette politique de temps en temps. Les modifications majeures seront annoncées via newsletter.

12. Nous Contacter

Pour toute question sur cette politique ou vos données personnelles:

  • 📧 Contacte-moi via le formulaire
  • 🌐 À Propos - Tous mes réseaux

13. Conformité RGPD - Résumé

TerraBloom est complètement conforme au RGPD:

  • ✅ Consentement explicite pour toute collecte
  • ✅ Pas de suivi non-consentant
  • ✅ Données minimales collectées
  • ✅ Droits d'accès, suppression, rectification respectés
  • ✅ Pas de partage de données sans consentement
  • ✅ Sécurité des données garantie
